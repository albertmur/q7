## MIME
- Mutipurpose Internet Mail Extensions
- Cabecerca que me dice que me voy a encontrar y después tenemos el body
	- Caracteristica fundamenteal: es recursivo -> dentro del body me puedo encontrar otro conjunto header-body
		- Las distintas partes que podemos tener se separan con un boundary
		- Vamos a poder enviar cualquier tipo de cosa dentro
- Como en la práctica queremos enviar imágenes, vamos a usar multipart. 
- La cabecera content-type es la que me dice el contenido de lo que viaja en mis mensajes
- Fijarse del ejemplo que las distintas partes estan separadas por boundaries.
- Definimos el multipart/form-data : para decir como llega la información
## HTML
- Hypertext Markup Language
- Cada navegador interpreta de manera diferente el Markup Language
- Cómo se usan los tags HTML?
	- Definir cabecera de documentación
	- Los tags son para definir los elementos y la estructura de nuestra página (documento)
- Cómo se usan los atributos?
	- Permiten configurar cosas sobre un elementos
	- Terminología:
		- tag:
			- \<form
		- atributo:
			- action="destino"
			- method"POST"
			- le estoy diciendo como configurar el formulario

## XML
- eXtensible Markup Language
- En HTML no nos podemos inventar un tag
- Estructura en arbol
- Elementos, atributos y texto (mirar ejemplo)
- Sintaxis:
	- Se tiene que establecer que es xml en la primera línea
	- Cerrar tags es obligatorio
	- Los tags son case sensitive
	- Los elementos se pueden poner unos dentro de otros
	- Solo puede haber un elemento raiz
